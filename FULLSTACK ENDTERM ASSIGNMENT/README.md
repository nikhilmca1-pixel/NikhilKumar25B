# FULLSTACK ENDTERM ASSIGNMENT

This project contains 13 independent assignment solutions. Each question has its own folder.

## Browser questions (Q1–Q7, Q13)
Open the folder's `index.html` in a browser. For the API questions, internet access is required.

## Node / Express questions (Q8–Q12)
Install Node.js (LTS), open the relevant folder in VS Code terminal, then run:
```bash
npm install
npm start
```
Use the local URL printed in the terminal.

- Q8: Express routes + EJS template engine
- Q9: REST CRUD in-memory product data
- Q10: Product API + client-side rendered frontend
- Q11: REST CRUD + MongoDB (set `MONGODB_URI` in `.env`)
- Q12: E-commerce demo with seller panel, cart, checkout simulation, and orders

Q12 checkout is a demonstration flow, not a real payment gateway. Do not enter real card details.
Q11 requires a running MongoDB instance or MongoDB Atlas connection string.
